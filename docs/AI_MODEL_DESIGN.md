# AI Model Design & Machine Learning Architecture

## 1. Module A: Probabilistic Content Detection Methodology

### 1.1 Critical Scientific & Ethical Operating Principles
1. **Never Claims to Prove Authorship**: The detection engine evaluates linguistic distributions, statistical anomalies, and language model predictability. It **never claims to prove AI authorship or human authenticity**.
2. **Standard Terminology**: The primary document-level metric is designated as **`synthetic_pattern_confidence`** ($[0.0, 1.0]$), reflecting the statistical alignment of the text with machine generation patterns rather than an absolute authorship probability.
3. **No LLM Self-Assessment**: Under no circumstances will the system use an "Ask an LLM if this is AI" approach.
4. **Sentence Attribution vs. Document Decision**: Sentence-level scores are strictly **exploratory local variance indicators**. Highlighting indicates localized statistical homogeneity; it does not constitute independent proof that a sentence was generated by AI.
5. **Length Gating (Initial Design Choices)**:
   - Text $< 50$ words: Rejected for document-level analysis due to severe statistical variance.
   - Text between $50 - 150$ words: Processed but explicitly flagged with `LOW_RELIABILITY_LENGTH`.
   - Sentences $< 10$ words: Excluded from sentence-level synthetic highlighting (`INSUFFICIENT_LENGTH`).
   *Note: These word-count thresholds represent initial engineering design choices and will be empirically evaluated during benchmarking.*

#### Safe Local Model Strategy (RTX 2050 4GB VRAM):
- Peak VRAM and RAM are never assumed to be fixed; they are actively measured, profiled, and logged during inference.
- GPU models (`DistilGPT-2`, `DistilRoBERTa`) utilize FP16 precision, configurable mini-batching (`eval_batch_size: 4`), and safe fallback to CPU if CUDA initialization or allocation fails.

### 1.3 Calibration & The Configurable Decision Bands

Uncalibrated classifier outputs produce extreme confidence values near $0.0$ or $1.0$. The system applies **Isotonic Regression** (with Platt Scaling as a fallback for smaller validation sets) on held-out data.

#### Three-Tier Classification Bands:
The decision boundaries are established with an initial configurable **Abstain Band** ($[0.40, 0.60]$), subject to empirical calibration:

| Confidence Range | Classification Band | Meaning & User Guidance |
|---|---|---|
| **$0.00 \le \text{Score} < 0.40$** | **`HUMAN_TYPICAL`** | Characteristics strongly align with typical human stylistic and lexical variance. |
| **$0.40 \le \text{Score} \le 0.60$** | **`INCONCLUSIVE`** *(Abstain Band)* | **System abstains from classification.** Text features fall into overlapping distributions. Editorial review required. |
| **$0.60 < \text{Score} \le 1.00$** | **`SYNTHETIC_INDICATIVE`** | Characteristics exhibit statistical homogeneity, low burstiness, or patterns typical of machine text. |

*Note: The $0.40 - 0.60$ thresholds are initial configurable parameters and will be refined based on validation reliability curves.*

### 1.4 Benchmark Strategy, Evaluation Categories & Data Leakage Prevention

#### 1. Evaluation Categories:
To evaluate true cross-model generalization, the benchmarking pipeline partitions test data into three distinct evaluation classes, alongside diverse human-written corpora:
1. **In-Distribution Generators**: Model families seen during development (e.g., GPT-3.5, Mistral-7B).
2. **Out-of-Distribution / Unseen Generators**: Completely unseen generator architectures (e.g., Gemini 1.5, Llama-3.3, Claude 3.5, Command R+).
3. **Human-Edited AI-Generated Text**: AI-generated texts that have undergone human stylistic revision, sentence reordering, or vocabulary substitution.
4. **Diverse Human-Written Corpora**: Multi-domain human samples spanning academic papers, student essays, journalism, creative writing, and non-native English essays (e.g., TOEFL).

#### 2. Data Leakage Prevention:
- **Strict Prompt-Disjoint Splitting**: Splits **must never share prompts, topics, or underlying source documents**. If prompt $P_k$ exists in training, all human and AI completions of $P_k$ are quarantined from validation and test sets.
- **Deduplication**: Exact and near-duplicate MinHash LSH deduplication across all corpora.
- **License Compliance**: Datasets must possess verified permissive licenses (CC-BY, MIT, Apache 2.0).

#### 3. Operating Metrics:
- **True Positive Rate (TPR) at Fixed False Positive Rates (FPR)**: Evaluated at strict operating thresholds: $\text{TPR at } \text{FPR} \le 1\%$ and $\text{TPR at } \text{FPR} \le 5\%$.
- Precision, Recall, F1-Score, ROC-AUC, PR-AUC.
- **Expected Calibration Error (ECE)** and Brier Score.
- **Subgroup False Positive Audit**: Specific tracking of FPR on non-native English writing to measure and mitigate linguistic bias.

## 2. Module B: Writing Improver Architecture

### 2.1 Design & Ethical Boundaries
The Writing Improver is designed strictly for **clarity, conciseness, readability, and professional tone alignment**. It is **not** an evasion or stealth rewriting tool. It preserves factual meaning, numbers, dates, units, and citations.

---

### 2.2 Expanded Protected-Span Extraction Engine

Before passing text to an external LLM, sensitive spans are extracted deterministically via regex patterns and named-entity recognition (`spaCy`), replaced with typed tokens, and unmasked post-transformation:

```
Source:
"On November 12, 2023, Dr. Grant did not find 42.8 kg of specimens in Area 51 (Smith et al., 2021)."

Masked:
"On {{DATE_1}}, {{PERSON_1}} {{NEG_1}} find {{NUM_1}} {{UNIT_1}} of specimens in {{LOC_1}} {{CITE_1}}."
```

#### Protected Entity Categories:
1. **Negation & Modality**: `not`, `never`, `neither`, `no`, `without`, `hardly`, `cannot`, `must`, `may`.
2. **Factual Numbers & Values**: Integers, decimals, percentages, monetary amounts (`$45.50`, `12%`).
3. **Dates & Temporal Anchors**: Explicit dates (`November 12, 2023`, `2024-05-01`, `Q3 2022`).
4. **Measurement Units**: Metric and imperial units (`kg`, `ml`, `km`, `Hz`, `mmHg`, `mg`).
5. **Citations & References**: `(Smith et al., 2021)`, `[12]`, `doi:10.1038/...`.
6. **Code, Identifiers & URLs**: Markdown backticks, programming syntax, web URLs, email addresses.
7. **Technical Terms & Named Entities**: Organizations, individuals, specialized terminology.

---

### 2.3 Rewriting Modes & Hosted Provider Strategy

Six modes supported: *Natural/Conversational*, *Academic Clarity*, *Professional*, *Simple/Readable*, *Concise*, *Formal*.  
All generative rewrites route through external hosted APIs (Groq, OpenRouter, Anthropic, OpenAI) via the abstract `LLMProvider` interface to preserve local VRAM.

## 3. Post-Rewrite Verification Layer (Meaning Preservation)

### 3.1 Verification Principle: Cosine Similarity is a Heuristic, Not a Guarantee
Embedding cosine similarity evaluates proximity in latent vector space; **it cannot prove semantic equivalence, factual identity, or logical preservation**. BundCheck enforces a multi-tier deterministic and NLI audit running **purely on CPU**.

```
                    ┌───────────────────────────────────┐
                    │  Original Text vs. Rewritten Text │
                    └─────────────────┬─────────────────┘
                                      │
         ┌────────────────────────────┼────────────────────────────┐
         ▼                            ▼                            ▼
┌───────────────────┐       ┌───────────────────┐       ┌───────────────────┐
│ Tier 1: Factual   │       │ Tier 2: Logical   │       │ Tier 3: Named     │
│ Values, Dates,    │       │ Polarity Diff     │       │ Entity & Citation │
│ Units & Numbers   │       │ (Negation Dropped)│       │ Integrity (NER)   │
└────────┬──────────┘       └────────┬──────────┘       └────────┬──────────┘
         │                           │                           │
         └───────────────────────────┼───────────────────────────┘
                                     │
         ┌───────────────────────────┴───────────────────────────┐
         ▼                                                       ▼
┌───────────────────────────────┐       ┌───────────────────────────────┐
│ Tier 4: NLI Contradiction     │       │ Tier 5: Paragraph Semantic    │
│ Check (DeBERTa-v3 on CPU)     │       │ Embedding Proximity (MiniLM)  │
└──────────────┬────────────────┘       └──────────────┬────────────────┘
               │                                       │
               └───────────────────────┬───────────────┘
                                       ▼
                    ┌─────────────────────────────────────┐
                    │    Verification Report Evaluator    │
                    │   (Severity Classification)         │
                    └──────────────────┬──────────────────┘
                                       ▼
                    ┌─────────────────────────────────────┐
                    │   PASSED / NEEDS_REVIEW / FAILED    │
                    └─────────────────────────────────────┘
```

### 3.2 Audit Subsystems & Severity Levels

1. **Deterministic Value, Date & Unit Diff**:
   - Compares multisets of numbers, dates, and units between source and target.
   - Any dropped, altered, or hallucinated value triggers a `CRITICAL: VALUE_OR_UNIT_MUTATION` flag.
2. **Negation & Polarity Audit**:
   - Detects omitted or inverted negation tokens. Dropping a negation (e.g., "did not agree" $\to$ "agreed") triggers a `CRITICAL: NEGATION_INTEGRITY_VIOLATION`.
3. **Citation & Entity Association Diff**:
   - Verifies all citations and key named entities remain intact in proper paragraph contexts. Missing citations trigger `CRITICAL: CITATION_LOST`.
4. **Natural Language Inference (NLI) Contradiction Check**:
   - Evaluates source-target sentence pairs using `cross-encoder/nli-deberta-v3-small` on CPU.
   - If $P(\text{Contradiction}) > 0.10$, triggers `CRITICAL: CONTRADICTION_DETECTED`.
5. **Paragraph Semantic Embedding Proximity (Heuristic)**:
   - Cosine similarity via `all-MiniLM-L6-v2` on CPU.
   - Score $\ge 0.88$: Normal pass.
   - Score $0.75 - 0.88$: Flagged as `NEEDS_REVIEW`.
   - Score $< 0.75$: Marked `POTENTIAL_SEMANTIC_DRIFT`.
